Agent safety

The agent trades your rules inside hard limits. It can trade. It can never withdraw.

Three modes

  • Paper: simulated fills. Every new agent starts here.
  • Assisted: it finds the signal. You place the trade.
  • Autonomous: it places real orders. You type a confirmation to turn it on.

The key

  • An order-only key. It can place and close orders. It cannot withdraw funds.
  • Stored encrypted. Every change to an agent needs your wallet’s signature.
  • Your funds stay in your own Orderly account. We never hold them.

Limits you set

  • A daily-loss cap. A max number of trades per day. Size and leverage per trade.
  • Each live position (DCA ladders aside) also rests a reduce-only stop on the exchange, beyond the agent’s own stop. If our servers stall, the position still has a stop.

Stopping it

  • Pause: no new entries. It still manages the open position.
  • Deactivate: stops and deletes the key. The open position stays open. The app warns you first.
  • Kill: closes the position, deletes the key, stops. One tap.
